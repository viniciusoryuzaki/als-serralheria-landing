# ALS Serralheria e Automação — Landing Page Oficial

Landing Page moderna, de alto padrão e responsiva para a **ALS Serralheria e Automação**, especializada em portões esculturais automatizados, esquadrias metálicas, corrimões em inox e toldos sob medida em Curitiba e Região Metropolitana.

![ALS Serralheria e Automação](assets/logo.png)

---

## 🚀 Tecnologias Utilizadas

- **HTML5 Semântico**
- **Tailwind CSS (CDN)** para estilização utilitária de alta performance
- **CSS3 Customizado** (`styles.css`) com suporte a Glassmorphism, paleta White Luxury e acentos em vermelho vivo (`#D91E28`)
- **JavaScript Moderno (ES6+)** (`script.js`):
  - Sistema interativo de filtragem por categorias na galeria de projetos
  - Cálculo de proximidade e tempo de rota via Geolocation API (Fórmula de Haversine)
  - Integração com YouTube Player e Google Maps
- **Fontes**: Google Fonts (*Montserrat* e *Inter*)
- **Ícones**: Font Awesome 6

---

## 📌 Funcionalidades

1. **Header & Top Bar White Luxury**: Fundo branco sólido com logotipo da marca e botão direto de WhatsApp `41 9999999`.
2. **Hero Section Dinâmica**: Apresentação de impacto com vídeo oficial do YouTube incorporado e botões de ação rápida.
3. **Categorias de Fabricação**:
   - Portões Automáticos & Esculturais
   - Esquadrias Metálicas Minimalistas
   - Corrimões & Guarda-Corpos em Inox
   - Toldos & Coberturas Metálicas
4. **Galeria de Obras com Filtros**: Catálogo interativo com filtros por categoria e efeitos de hover.
5. **Localização & Cálculo de Rota**:
   - Sede: *Rua Professor José Demeterco, 190 - Cajuru, Curitiba - PR*
   - Google Maps interativo integrado
   - Calculadora de distância em tempo real para o visitante
6. **Design 100% Responsivo**: Otimizado para smartphones, tablets e desktops.

## 🛠️ Como Executar Localmente

Basta clonar o repositório e abrir o arquivo `index.html` em qualquer navegador:

```bash
# Clonar o repositório
git clone https://github.com/viniciusoryuzaki/als-serralheria-landing.git

# Acessar a pasta
cd als-serralheria-landing

# Abrir no navegador ou iniciar um servidor local
python -m http.server 3000
```
